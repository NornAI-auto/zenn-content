## はじめに

現在、個人で16本のマイクロSaaSを稼働させている。

月収ベースで見ると1本あたり数千円〜数千円規模のものが多いが、それが積み重なると無視できない収益になる。ただ、ここに至るまでに「市場調査」で大量の時間を溶かしてきた苦い経験がある。

最初の頃は、Twitterで「フリーランス 困ってること」と検索し、Redditを眺め、はてブのホットエントリを毎朝手でチェックしていた。1アイデアを検証するのに平均で3〜4時間かかっていた。それを週に何本もやるのは、正直しんどい。

そこで市場調査フローそのものを自動化することにした。この記事ではその仕組みと、実際に得られた知見を正直に書く。

---

## 課題：調査コストが高すぎてアイデア検証が進まない

マイクロSaaSで重要なのは「小さなペインを見つけて、小さく作って、早く出す」ことだ。

ところが「小さなペインを見つける」フェーズに一番時間がかかっていた。具体的には以下のような作業を毎回手でやっていた。

- Google検索で競合調査（キーワードを変えながら何十回も）
- Twitter/Xで愚痴ツイートを探す
- はてなブックマークのホットエントリを確認
- Indie Hackersの最新スレッドを読む
- 結果をNotionにまとめる

これを複数の市場セグメント（フリーランス・中小企業・webdev）に対してやるとなると、週に10時間以上消えることもあった。

---

## 解決策：調査クエリを自動実行してSlackに流す

発想はシンプルで、「毎日実行したいGoogle検索クエリをリスト化して、結果を自動でSlackに投げる」というものだ。

技術スタックはこう決めた。

- **n8n**：ワークフロー自動化（セルフホスト）
- **SerpAPI**：Google検索結果の取得
- **GPT-4o-mini**：結果の要約・ペイン抽出
- **Slack Webhook**：通知配信

n8nを選んだのは、ノーコードで組めるのにコードも書けるからだ。WorkflowNagBot（月2,850円で運用中）を作るときにn8n周りのノウハウが溜まっていたのも大きい。

---

## 実装：クエリリストとn8nワークフロー

まずクエリは以下のようなJSONで管理している。セグメントごとに調査したい軸を定義する形式だ。


{
  "segments": [
    {
      "name": "JP_freelancer",
      "queries": [
        "フリーランス 請求書 自動監視 月額課金 日本 2026 未",
        "フリーランス 確定申告 自動化 つまずき 2026",
        "個人事業主 業務効率化 不満 ツール 2026"
      ]
    },
    {
      "name": "webdev_tools",
      "queries": [
        "micro SaaS launch indie hackers 2025",
        "Japan SMB software gap english tool no japanese version 2026"
      ]
    }
  ]
}


n8n側では、このJSONを読み込んでSerpAPIにリクエストを投げ、返ってきた上位5件のタイトルとスニペットをGPT-4o-miniに渡す。プロンプトはシンプルにこうしている。

text
以下の検索結果から、個人開発者がマイクロSaaSで解決できる
「未解決のペインポイント」を3行以内で箇条書きにしてください。
競合がすでに強力に解決しているものは除外してください。

検索結果:
{{検索結果スニペット}}


これをSlackに流すと、毎朝「今日の調査まとめ」が届く。読むのに5分かからない。

実際にこのフローから生まれたのが **FreelancePainPollBot（月4,350円）** だ。「フリーランサーの細かい困りごとが可視化されていない」というペインは、このSlack通知を見ていて気づいたものだった。

---

## 運用してわかったこと（正直に書く）

**よかったこと：**

- 毎日調査コストがほぼゼロになった
- 「なんとなく気になってた市場」を数値で比較できるようになった
- SoloTaxReceiptBot（月1,350円）のような細かいニッチも拾えるようになった

**微妙だったこと：**

- SerpAPIは月1,000リクエストを超えるとコストが上がる。クエリ数は絞った方がいい
- GPTの要約が「それっぽいけど薄い」ことがある。プロンプト調整は継続的に必要
- 「ペインがある」と「お金を払う」は別の話。調査はあくまで仮説出しに過ぎない

16本運用している今も、全部が「大当たり」ではない。月1,350円のものもあれば月4,350円のものもある。自動化によってアイデアの母数を増やせたのは事実だが、検証はやはり人力だ。

---

## まとめ

市場調査の自動化で変わったのは「速度」と「習慣」だった。毎日Slackを開くだけで市場の変化に気づける状態になり、アイデア出しが苦痛でなくなった。

個人開発者で「アイデアが出ない」「調査に時間がかかりすぎる」と感じている人には、まずクエリリストを作ってSerpAPI＋n8nで流す構成から試してほしい。最小構成なら半日で動く。
